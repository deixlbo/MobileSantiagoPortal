# User Acceptance Testing (UAT) Form

## Project Information
- **Project:** Barangay Santiago Portal
- **Team:** SDG Forge
- **Date:** June 2026
- **Prepared by:** SDG Forge

## Purpose
This form documents the acceptance testing of the Barangay Santiago Portal, verifying that the system meets the functional requirements for resident registration, document requests, official workflows, and communication.

## Instructions for Testers
1. Execute each test case using the portal interface.
2. Record the actual result and status for each step.
3. Provide comments for any deviations or issues.
4. Sign the acceptance section once all required criteria are met.

## Acceptance Criteria
- All critical workflows complete successfully.
- Resident registration and login function correctly.
- Document request submission and tracking work as expected.
- Official review and approval workflows function correctly.
- Complaint reporting and announcement delivery are verified.
- Private document storage and access controls are enforced.
